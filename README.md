# Blender GTR2 GMT Importer

This plugin allows you to import GMT files from the classic racing game **GTR2** directly into Blender. It supports importing track and car models, including their associated materials.

## Features

| Feature | Status |
|:---|:---|
| GMT 3D Models Import (Tracks & Cars) | ✅ |
| Material Import | ✅ |

## Known Bugs
* **Alpha Channel:** The alpha channel (transparency) of textures is currently not configured automatically in Blender and must be adjusted manually.

---
